## 🚀 Featured projects

### 💳 [Credit Card Fraud Detection Analysis](https://github.com/SrilekhaGajoju/credit-card-fraud-analysis)
`Python` `MySQL` `SQL` `Power BI`

End-to-end analysis of **555,719 transactions** to find when, where and how fraud happens. Data is cleaned in Python, loaded into a MySQL star schema, analysed with SQL (CTEs, window functions, views) and presented in a six-page Power BI report.

- **84%** of fraud happens between 10 PM and 4 AM, when only 23% of transactions occur
- Online shopping categories account for **80% of all fraud loss** ($1.13M total)
- Fraud comes in bursts: a hit card averages ~10 fraud transactions within 3 days

`Python` `pandas` `yfinance` `MySQL` `ETL`

An automated ETL pipeline that pulls daily OHLCV data for AAPL, MSFT, GOOGL, AMZN and TSLA into a 5-table relational model, replacing manual downloads.

- Processes **315 rows in 3.5 seconds**, with **100% success** across the last 5 runs and 0 rejected rows

- Analyses returns, 20-day moving averages and 10-day rolling volatility
